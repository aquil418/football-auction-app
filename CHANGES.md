# LEAGUE Changes

## Viewer Team Overview

- Added a **Teams** section to the Viewer dashboard.
- Viewers can now see every configured team's:
  - Team name
  - Manager name
  - Remaining budget/balance
  - Number of players bought
  - Names of all players bought
  - Purchase price for each bought player
- The team list updates automatically from the same synchronized auction state used by the rest of the app.
- No database/schema changes are required.
- Existing card reveal animation and auction functionality are preserved.
